# 市场通用新闻简报

## 目标

在每个交易日开盘前整理国内外局势、时下热点、重要政策、宏观数据和近期重要事件落地情况，为 A 股及跨市场观察提供可追溯的信息底稿。

本目录只做公开信息整理，不构成投资建议。

## 运行规则

- 常规任务：周一至周五 08:10（Asia/Shanghai）。
- 中国大陆法定休市日仍可运行，但报告必须标注“休市日”，内容转为跟踪休市期间的政策、国际市场和事件变化。
- 首次运行：回溯 30 个自然日，生成背景基线，不补造历史日报。
- 后续运行：覆盖“上次成功运行时间至本次运行时间”的滚动窗口。
- 重大事件快报：默认人工触发；达到“重大事件门槛”时可按需生成。
- 无重大新增事件时仍生成简短日报，并记录检查和异常。
- 数据来源不足时不生成正常“无新闻”结论，改为“数据获取异常”报告。

## 收录边界

优先收录：

- 央行、财政、监管、交易所和国家级产业政策；
- 国内外宏观数据及其明显偏离预期的情况；
- 战争、制裁、封锁、重大地缘冲突和供应链中断；
- 已排期重大军事演习、部署、出口管制和区域安全事件进入执行或升级阶段；
- 中东与红海、俄乌与欧洲、台海与南海、朝鲜半岛、南亚等区域安全环境出现实质变化；
- 对多个行业有影响的供需、价格、技术和监管变化；
- A 股行业层面的重大变化及龙头公司的广泛影响事件；
- 下一交易日或未来 48 小时的重要数据、会议和裁决。

原则上不收录：

- 纯宣传、无新增事实的重复报道；
- 单一公司一般性公告、宣传稿和未被市场广泛关注的人事变动；
- 未经核验的社交媒体消息；
- 无法确认发布时间或来源的“网传”内容；
- 已充分预期且没有新增信息的旧闻。

已排期事件不适用“首次公告在窗口内”这一条。重大演习、政策生效、峰会、议息会议等如已进入执行窗口或出现实质更新，必须重新核验，不能因为初始公告早于本次滚动窗口而跳过。

## 重大事件快报门槛

满足任一条件可触发快报：

- 央行、财政、监管或交易所发布重大政策；
- 战争、制裁、封锁或重大地缘冲突升级；
- 关键宏观数据显著偏离预期；
- 原油、黄金、汇率或美债出现异常波动；
- 影响多个行业的重大供需、技术或监管事件。

## 来源与核验

1. 政策、数据和监管结论以官方原文为准。
2. 权威媒体仅可作为“媒体先导”，正式结论必须等待官方确认。
3. 重大事件尽量使用两个独立来源交叉核验。
4. 每条信息保留来源机构、原文标题、发布时间、抓取时间、原文链接和核验状态。
5. 来源冲突时保留不同说法，并优先标注官方最新口径。
6. 无法访问、仅抓到部分内容、旧页面或付费墙必须如实记录。
7. 只保存摘要、结构化元数据和链接，不保存网页全文。

## 双轨采集

本目录采用“媒体发现、官方定稿”的双轨机制。两条轨道必须在报告中分开呈现，不能把媒体热点混入“已确认事实”。

### 媒体发现层

- 每次运行扫描新华社、央视新闻、财联社、美联社和 BBC；路透社、NHK World、共同社可访问时同时扫描。
- 目标是发现时下热点、突发事件、市场情绪和可能影响多个行业的题材。
- 媒体热点写入日报的“媒体热点扫描”专区，并标注 `媒体先导` 或 `媒体交叉`。
- 单一媒体报道不上升为正式事实；两个独立媒体一致可标为 `媒体交叉`，但仍不等于官方确认。

### 官方核验层

- 对媒体热点按政策、数据、监管、国际事件等类别寻找官方原文。
- 地缘与安全事件固定检查日本防卫省、美国印太司令部及涉事国家国防部门；涉及重大演习时以官方演习公告为准。
- 官方已发布的，写入“已确认事实”并附官方链接。
- 官方尚未发布的，保留在“媒体热点扫描”，不得改写成确定结论。
- 官方口径与媒体初步报道不一致时，以官方为准，同时保留修订记录。

日报应同时回答两个问题：

1. 今天市场正在关注什么，即使部分信息还没有官方定稿；
2. 这些热点中，哪些已经得到官方确认，哪些仍然只是媒体线索。

### 持续事件与战略日历

- `events/active.md` 中的持续性事件每轮必须检查，不因滚动窗口没有新的媒体热度而忽略。
- 每轮至少快扫以下区域：中东与红海、俄乌与欧洲、台海与南海、朝鲜半岛、南亚；其他地区有活跃冲突时一并纳入。
- 维护未来 30 天的重大政策生效日、议息会议、选举、峰会、军演、制裁期限和供应链节点。
- 已排期事件进入执行阶段、临近 48 小时、规模或地点发生实质变化、出现官方升级表态时，视为本轮新增信息。
- 重大军事演习不得仅因对 A 股没有直接映射而删去；应说明对区域风险、能源、航运、军工、供应链和避险资产的观察意义。
- 持续事件在日报中使用独立章节呈现，不占用 3—8 条突发媒体热点的名额。
- 对战争和袭击事件，交战方或相关政府的公开声明必须标明“当事方说法”；只有独立来源一致或可核实证据支持时才写成已确认事实。
- 区域官方来源不可用时，不能写成“无变化”，应标注核验受限，并保留权威媒体先导。

核验状态统一使用：

- `已确认`：官方来源可读，或两个独立可靠来源一致；
- `媒体先导`：权威媒体已报道，但官方尚未确认；
- `媒体交叉`：两个独立权威媒体报道一致，但官方尚未确认；
- `待确认`：来源单一、信息相互冲突或缺少发布时间；
- `部分获取`：页面可读，但关键正文、附件或数据不完整；
- `未获取`：页面、正文或链接不可用；
- `已更正`：后续信息修正了先前记录；
- `已失效`：事件条件不再成立或政策已被替代。

## 来源不足判定

核心来源访问成功率低于 60%，或国内官方、国际官方两类来源均无法取得有效页面时，当日报告必须标记为“数据不足”。

核心来源至少包括：

- 中国政府网；
- 中国人民银行；
- 国家统计局；
- 国家发展改革委；
- 中国证监会官网首页或直接文章；
- 上海证券交易所；
- 美联储；
- 美国劳工统计局；
- 美国财政部；
- 欧洲央行；
- IMF；
- 至少一家国内权威媒体和一家国际权威媒体。

## 目录

```text
news/
  README.md
  sources.md
  baselines/                 # 首次回溯和阶段性背景
  daily/YYYY/                # 每日简报
  flashes/YYYY/              # 重大事件快报
  events/active.md           # 活跃事件
  events/archive.md          # 已结束事件
  logs/source-checks.md      # 来源检查和异常
  logs/event-revisions.md    # 事件修订历史
  logs/run-log.md            # 运行记录和滚动窗口起点
  templates/                 # 模板
```

## 文件命名

- 日报：`daily/YYYY/YYYY-MM-DD.md`
- 快报：`flashes/YYYY/YYYY-MM-DD-HHMM-主题.md`
- 背景基线：`baselines/YYYY-MM-DD-30-day.md`
- 同一天需要重跑时，更新同一日报并在“修订记录”中追加说明，不创建含糊的副本。

## 事件状态与归档

状态统一为：

- `待确认`
- `发展中`
- `已落地`
- `已解除`
- `已失效`

事件明确结束、政策正式实施且无需继续追踪，或连续 30 天没有实质增量时，可移入 `events/archive.md`。长期政策、战争、贸易限制等仍在影响市场的事件继续留在活跃台账。

## 事实、分析与观察点

报告必须分开呈现：

- **已确认事实**：只写来源明确、可核验的信息；
- **市场解读**：明确标注为分析判断，说明可能的市场传导路径；
- **观察点**：给出未来需要验证的数据、政策、价格或时间节点，不直接给买卖建议。

## 运行步骤

1. 读取 `sources.md`、`events/active.md` 和最近一次成功运行记录。
2. 检查持续事件和未来 30 天战略日历，确认是否有事件进入执行阶段或出现实质更新。
3. 先扫描国内和国际权威媒体，形成 3—8 条热点候选。
4. 检查核心官方来源，并为热点寻找官方原文或第二个独立来源；军事演习同时检查日本防卫省和美国印太司令部。
5. 按滚动窗口筛选新增和实质更新信息，记录成功、部分获取和失败；已进入执行阶段的排期事件按实质更新处理。
6. 按模板生成日报或异常报告，单列“媒体热点扫描”和“持续事件与战略日历”。
7. 更新事件台账和修订历史，只追加，不抹除旧记录。
8. 在运行日志记录成功状态、报告路径、收录数量、异常数量。
9. 通知只显示运行时间、收录数量、异常数量和报告路径。

## 运行环境限制

定时任务需要本机保持开机、ChatGPT 桌面应用保持运行，且 `D:\A-shares` 可访问。公开网页不可用、登录限制、反爬策略或网络故障都可能导致部分来源缺失，报告不得隐瞒。
